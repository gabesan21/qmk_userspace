# Script `scripts/build_flash.sh`

Script bash executável criado como caminho único de build/flash local: preflight fail-fast (qmk, submódulo `modules/bastardkb`, `user.qmk_home`) com comando corretivo exato por falha; compile do padrão `bastardkb/dilemma/3x5_3_procyon:vendor` sobrescrevível por `-k`/`-m`; flash UF2 somente via `--flash`, com instruções de bootloader e espera de 60 s pelo volume `RPI-RP2`. Mensagens pt-BR, cores com `NO_COLOR`. Detecta e instrui, nunca configura; a execução ficou reservada ao dono.
