# Acentos e barra na Base

No layout `us-intl`, segurar `Q/W/E/U/I` envia grave/til/agudo/trema/circunflexo; tocar mantém a letra. A barra dá `/` no toque e `?` ao segurar. `Z` permanece como único atalho manual para Pointer na Base.
