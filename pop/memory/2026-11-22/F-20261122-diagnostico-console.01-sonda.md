# Sonda manual de telemetria

Uma consulta VIA de leitura identifica o estágio do emissor mesmo quando o console está silencioso. O contador mede enfileiramento, não entrega USB. A ferramenta compara duas amostras com os pacotes recebidos; o comando não suportado caracteriza ausência da sonda, não do firmware de camadas.
