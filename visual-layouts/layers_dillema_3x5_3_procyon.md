# Mapa de teclas — Dilemma `3x5_3_procyon` (keymap `vendor`)

> **Fonte:** `keyboards/bastardkb/dilemma/3x5_3_procyon/keymaps/vendor/keymap.c`
> Layout inspirado no [Miryoku](https://github.com/manna-harbour/miryoku), adaptado para o Dilemma com trackball (Procyon).

## Legenda

| Símbolo | Significado |
|---------|-------------|
| `A (⌘)` | Toque = letra · **segurar** = modificador: `⌘` GUI · `⌥` Alt · `⌃` Ctrl · `⇧` Shift · `AGr` AltGr |
| `Z (PTR)` | Toque = letra · **segurar** = ativa a camada indicada |
| `ESC/MED` | Toque = tecla · **segurar** = camada (tap-hold `LT`) |
| `✕` | Sem função nesta camada (`XXXXXXX`) |
| `▽` | Transparente — herda a tecla da camada abaixo (`_______`) |

## Como ativar cada camada

| Camada | Segurar |
|--------|---------|
| 1 · Function | `TAB/FUN` (polegar esq.) |
| 2 · Navigation | `SPC/NAV` (polegar esq.) |
| 3 · Media | `ESC/MED` (polegar esq.) |
| 4 · Pointer | `Z` ou `/` |
| 5 · Numeral | `BSP/NUM` (polegar dir.) |
| 6 · Symbols | `ENT/SYM` (polegar dir.) |

## Encoders (giro anti-horário / horário)

| Camada | Encoder esquerdo | Encoder direito |
|--------|------------------|-----------------|
| Base | Scroll ↓ / ↑ | Volume − / + |
| Function | ↓ / ↑ | ← / → |
| Navigation | Page ↓ / ↑ | Volume + / − *(invertido)* |
| Media | Page ↓ / ↑ | Volume + / − *(invertido)* |
| Pointer | RGB Hue − / + | RGB Saturação − / + |
| Numeral | RGB Brilho − / + | RGB Velocidade − / + |
| Symbols | RGB Efeito ◀ / ▶ | ← / → |
